Your agent sets up your machines. You approve every change.

Terran is a dependency-free Go CLI that AI agents use to place curated skills, instructions, configs, and tool lists at fixed harness destinations. It plans before changing anything, blocks unsafe collisions and drift, and records what it owns. It never prompts: your agent asks you, then passes your decision.

Get started

Install your AI coding agent (Claude Code, Codex, or OpenCode), open it on the machine, and tell it:

Set this machine up as a Terran Command Center.

Give it the catalog you trust and, if you keep one, your private overlay. The agent follows the agent guide in the README: it installs Terran from a pinned release, shows you a plan, and asks before every install, replacement, and login. It never pushes to git; you do.

Terran itself is installed from an exact release after inspecting install.sh, or built from a reviewed commit with Go 1.24 or newer. Release checksums detect corruption or mismatch, but do not replace source and publisher review.

Workflow

  1. Enroll. Your agent records one trusted local catalog and an optional private overlay, and names this Command Center.
  2. Plan. Every source, fixed destination, action, and reason is shown to you, with a digest.
  3. Apply. After your approval, Terran holds its lock, checks the digest, revalidates, then performs eligible work.
  4. Verify. Terran writes a private receipt; status and doctor report managed state, wider installation health, and every machine in your fleet.

A catalog can manage skills (managed copies), complete instruction files, config files, named agent, command, and hook files, owned keys in shared settings files, and a list of required tools. Items can be tagged for macOS or Linux only. Copied files change only through terran apply.

Collisions and drift

Terran never clears unrelated content to make a plan clean.

missing
Create after your approval.
exact safe match
Adopt it without changing the active file and retain a validated private backup.
safe differing item
Blocked until you choose, per item, to replace it (with a private backup) or keep it (held on this machine).
unsafe collision or receipt-owned drift
Stop. Unsafe file types or metadata, changed managed content, and changed backups are not overwritten.

doctor validates the full receipt, active managed inventory, every adoption backup, and required tools. Terran validates ownership, modes, links, boundaries, hashes, and fixed targets; it does not manage secrets, install other tools itself, or sandbox a malicious process running as the same user. Fleet status runs a fixed, read-only ssh command and returns only names, counts, versions, and commits.
