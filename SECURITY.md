# Security policy

Terran's source is public at <https://github.com/sean35mm/terran>. The latest released minor version receives security fixes; users should update to the newest patch in that minor line.

Terran's boundary excludes a malicious process running as the same user. Live skill symlinks intentionally reflect later edits in the trusted, user-owned enrolled repository. Global instructions are fixed-destination managed copies with exact-hash drift checks and private adoption backups. Terran protects against accidental collision, path substitution, and drift and rejects repositories, sources, targets, backups, and lock metadata outside the documented local-user ownership and mode boundary.

Report suspected vulnerabilities with GitHub's **Private vulnerability reporting** feature on the repository Security tab. If that feature is unavailable, open a GitHub issue containing only a non-sensitive summary and request a private reporting channel. Do not include exploit details, credentials, private paths, or other sensitive data in a public issue.

For ordinary non-sensitive bugs, open a GitHub issue with the Terran version, operating system, minimal reproduction, and redacted output.
